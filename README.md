# 🧪 OpenCart Software Quality Assurance Project

## 📘 Project Overview
This project focuses on performing **Software Quality Assurance (SQA)** activities for the **OpenCart e-Commerce Application**.  
The goal is to ensure that the OpenCart system meets its functional requirements and performs reliably across different modules.

## 🎯 Objectives
- To analyze and verify OpenCart’s functional requirements.  
- To design and execute detailed test cases for core modules.  
- To identify, document, and report software defects.  
- To provide full traceability from requirements to test results.

## 🗂️ Project Deliverables
The project includes the following key SQA documents:

| Document Name | Description |
|----------------|-------------|
| **OpenCart - FRS (Functional Requirement Specification)** | Defines the functional and non-functional requirements of the OpenCart system. |
| **OpenCart - Test Plan** | Outlines the overall testing strategy, objectives, scope, resources, and schedule. |
| **OpenCart - Test Scenarios** | Describes the high-level scenarios to be tested. |
| **OpenCart - Test Cases** | Contains detailed step-by-step test cases with expected and actual results. |
| **OpenCart - Test Execution Results** | Shows the results of executing the designed test cases. |
| **OpenCart - Bug Report** | Documents the identified defects, severity, and status. |
| **OpenCart - RTM (Requirements Traceability Matrix)** | Maps requirements to test cases to ensure full coverage. |

## 🧰 Tools & Techniques
- **Testing Type:** Manual Testing  
- **Bug Tracking Tool:** Google Sheets / Excel  
- **Documentation Tool:** Microsoft Word / Google Docs  
- **Testing Techniques:** Functional Testing, Regression Testing, UI Testing, Integration Testing  

## 📊 Key Outcomes
- Verified that major functional modules (Login, Add to Cart, Checkout, etc.) met business requirements.  
- Reported and tracked multiple defects with detailed documentation.  
- Ensured full traceability between requirements and test results using RTM.
